# Front-End de UCO Kudos

Interfaz React con Vite. El navegador usa `/api` en el mismo origen. Vite redirige esas solicitudes al backend.

- Para ejecutar la aplicación completa, sigue el manual de puesta a punto de la documentación de entrega.
- Desde `frontend/`, instala con `pnpm install --frozen-lockfile`. Ejecuta `pnpm check` y `pnpm build` para verificar y compilar.
- Con la aplicación completa y los datos de práctica cargados, ejecuta `pnpm exec playwright install chromium` y luego `pnpm test`.
